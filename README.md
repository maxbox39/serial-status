Плагін для [Lampa](https://github.com/yumata/lampa-source): кольорові **статуси серіалів** з TMDB, ручне перевизначення, фільтри та сортування.

## Можливості

### Бейджі на картках
- Статус серіалу в **нижньому лівому** куті картки
- Кольори:
  - 🟢 **В ефірі** 
  - 🔵 **У виробництві / Заплановано**
  - 🟠 **Пілот**
  - ⚪ **Завершений**
  - 🔴 **Скасований**

### Сторінка серіалу
- Кольоровий статус на повній картці
- Кнопка **«Статус»** (зручно з пульта TV)
- Меню:
  - змінити статус вручну
  - оновити з TMDB
  - скинути ручний статус

### Фільтри
- Показувати всі
- Тільки в ефірі / у виробництві
- Тільки завершені
- Сховати скасовані

### Сортування
- За роком (нові → старі / старі → нові)
- За рейтингом (↑ / ↓)

### Інше
- Кеш статусів (1–14 днів)
- Локальне збереження ручних статусів
- Очищення кешу та всіх перевизначень у налаштуваннях

---

## Налаштування

**Налаштування → Статус серіалу**

| Параметр | Опис |
|----------|------|
| Бейджі на картках | Увімкнути / вимкнути бейджі |
| Колір на сторінці серіалу | Фарбувати статус на full-картці |
| Оновлювати статус кожні | Термін кешу TMDB |
| Фільтр серіалів | Ховати картки за статусом |
| Сортування серіалів | Порядок у списках |
| Очистити кеш | Видалити закешовані статуси |
| Скинути ручні статуси | Видалити всі перевизначення |

## Сумісність

- Lampa (актуальні збірки з `SettingsApi`, `Select`, `Activity`)
- Пульт TV / D-pad (фокус після меню не губляється)

---

## Примітки

- Працює **тільки для серіалів** (TV), не для фільмів
- Ручний статус має пріоритет над даними TMDB
- Після зміни фільтра/сортування оновіть список (вийти й зайти знову)
